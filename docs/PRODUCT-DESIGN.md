# FixMyDoor product design

The product palette uses warm paper, pine for primary actions, mint for quiet surfaces, and copper for secondary emphasis. The shared stylesheet defines tokens, surface and button treatments, disclosure patterns, status treatments, and breakpoints. The homepage, portals and staff tools use the same palette and Inter interface typography.

- Homepage hero puts the service request first, provides a direct remote consultation entry point, and uses responsive versions of an existing gallery image.
- Invoice cards show the full payable figures in a wrapping grid. The invoice number and line items sit in a disclosure; receipt printing remains in the payment history.
- Recruitment shows one language at a time. Staff see compact applicant summaries and open contact details, qualifications and review actions as needed.
- Administrative tables stay in their own scroll region on wide screens, and booking cards serve phones and tablets.
- Set the artifact directory outside Git and run the browser design verifier against a synthetic local application. It checks nine representative widths, English and French recruitment, the remote booking entry point, staff review, portal invoice layout and receipt invocation. Set the optional axe script path for scoped accessibility checks.
